Método GET

                  

                  
    
                  
                  
    O que controla
    
                  
      
                  
      
                  
      
                
      
                
      
                  
      
                
      
                
      
                  
      
                
      
                
      
                  
      
                  
      Semântica no GET-LLM
      
                  
      
                  
      
                    No painel principal: Exportar pacote (GET-PACKAGE, reimportável) e, à parte,
                    GET-LLM (só leitura).
                  
      
                
      
              
      
            
      
          
      

          
      
            
      
            
      Estrutura documental
      
            
      
              Árvore do caderno de encargos. Seleccione um nó para ver associações; blocos abrem a preparação só
              quando pedir.
            
      
            
      
              
      
                
      Aviso: profundidade ≥ 5.
      
                
      
              
      
              
      
                
      Detalhe e associações
      
                
      Nenhum nó seleccionado.
      
                
      
                  
                
      
                
      
                
                
                
                
                
                
                
              
      
            
      
            
      
              Exportar estrutura
              
      
                
      
                  Exportação legível (não reimportável). Códigos documentais do estado actual do projecto. Para devolver
                  alterações à base, use GET-PACKAGE na Preparação do bloco ou em Exportar.
                
      
                
      
                
                
                
                
      
                  Pontos de desenvolvimento
                  
                  
                  
                
      
                
                
                
      
              
      
            
      

            
      
              Novo nó
              
      
                
                
                
                
                
                
                
                
      
                
      
              
      
            
      
          
      
      
      
        
      
        
      Árvore técnica
      
        
      Instalação do projecto (sistemas, equipamentos, funções) — distinta da estrutura documental do caderno.
      
        
      
          Instâncias técnicas
          
      
            
            
            
            
            
            
            
            
      
              
      
            
      
          
      
        
      

        
      
      

      
      
        
      
        
      Exportar para LLM
      
        
      
          Quatro saídas distintas: GET-PACKAGE (reimportável), roundtrip legado, GET-LLM
          (só leitura) e, na Estrutura documental, MD/PDF/XMind. Publique baseline antes de GET-PACKAGE.
        
      
        
      
          
      
            
      Baseline
      
            
      Baseline: desconhecida — publique antes do mestre.
      
            
            
          
      
          
      
            
      Pacote para discussão (fascículo)
      
            
      
              Ficheiro único GET-PACKAGE (.json) para a LLM; reimportar em Reimportar. Requer baseline
              publicada.
            
      
            
            
            
            
            
            
          
      
          
      
            
      Roundtrip legado (reimportação)
      
            
      
              Formato fascicle_roundtrip / mestre (avançado). Preferir GET-PACKAGE acima.
            
      
            
            
            
            
            
            
            
          
      
          
      
            
      Geração LLM (GET-LLM)
      
            
      
              Mestre + fascículo-índice + blocos em JSON/MD e ZIP. Estado live; não reimportável.
            
      
            
            
            
            
          
      
          
      
            
      Contexto LLM do projecto
      
            
      
              Metadados opcionais incluídos no JSON GET-LLM por bloco (não reimportável).
            
      
            
            
            
            
            
            
            
            
            
            
      
          
      
        
      
        
      
        
      

        
      
      

      
      
        
      
        
      Reimportar e decidir
      
        
      Incorpore o pacote devolvido pela LLM e decida proposta a proposta.
      
        
      Incorporar pacote
      
        
      Ficheiro GET-PACKAGE (.json) devolvido pela LLM.
      
        
        
        
        
        
      Reimportação legada

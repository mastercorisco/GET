# Diagramas do metodo GET (opcional)

| Artefacto | Uso |
|-----------|-----|
| [GET_METHOD_FLOW.drawio](../../GET_METHOD_FLOW.drawio) | Resumo **uma pagina** (abre bem no Cursor) |
| [GET_METHOD_ALL_SHEETS.drawio](../../GET_METHOD_ALL_SHEETS.drawio) | **6 folhas** (00–05), conteudo desta pasta reunido |
| `GET_METHOD_0x_*.drawio` | Uma folha cada (editar e voltar a fundir se mudares o multipage) |

Se a extensao Draw.io do Cursor falhar no multipage, abre `GET_METHOD_ALL_SHEETS.drawio` em [diagrams.net](https://app.diagrams.net) ou usa os ficheiros `0x` um a um.
